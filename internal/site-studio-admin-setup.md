# 모멘텀마케팅 홈페이지 제작툴 - 관리자 전용 설정

공개 고객 페이지: `/website-samples/`
관리자 로그인: `/admin/` (공개 메뉴에는 노출하지 않음)
기존 `/site-builder/*` 주소는 관리자 로그인으로 이동하며, 템플릿 CSS는 공개 샘플 경로로 복사됩니다.

## 운영 전 필수 설정

Vercel → momentum 프로젝트 → Settings → Environment Variables에서 두 변수 설정:
- `MOMENTUM_ADMIN_PASSWORD`: 16자 이상의 고유한 관리자 비밀번호. 코드나 고객 사이트에 작성하지 마세요.
- `MOMENTUM_SESSION_SECRET`: 추측할 수 없는 무작위 32자 이상의 비밀 문자열. 다른 프로젝트와 재사용하지 마세요.

Production 환경에 설정하고 다시 배포해야 활성화됩니다. 둘 중 하나라도 없으면 로그인 페이지 대신 503으로 차단합니다.
로그인은 6시간 만료되는 HttpOnly·Secure·SameSite=Strict 서명 쿠키를 사용합니다.
운영 전에는 Vercel 보안 기능에서 로그인 시도 속도 제한 및 가능하면 추가 인증을 설정하세요.
정적 샘플과 고객용 갤러리는 공개하고, 관리자 도구 자산은 관리자 인증 후 서버리스 함수가 제공합니다.
주의: 이 공개 GitHub 저장소의 소스 코드를 숨기지는 못합니다. 보호되는 것은 배포된 도구의 관리자 접근입니다.

## 고객 흐름
샘플 선택 → 선택한 디자인 카드 표시 → 해당 디자인 정보가 포함된 제작 상담 폼 → 견적 상담 → 관리자 제작툴에서 편집.

## 거래처·상품 관리 (초기 버전)

관리자 로그인 후 `/admin/crm/`에서 접속합니다. 고객용 홈페이지에는 링크가 나타나지 않습니다.
기본 상품 18종은 `site-builder/products.json`에 있고 관리자 브라우저 화면에서 추가 상품을 등록할 수 있습니다.
거래처별 복수 계약, 기간·수금·담당자·소개업체·수정횟수, 도메인/계약 만료일 60일·30일·7일 표시, 캘린더(.ics) 내보내기를 지원합니다.

**중요:** 현재 초기 버전은 browser localStorage에 저장하므로 실제 고객정보를 운영하는 정식 CRM으로 사용하면 안 됩니다. 안전한 고객 정보 관리는 로그인과 권한 관리가 있는 서버 데이터베이스, 데이터 백업, 접근감사 기능을 구현한 후 활성화해야 합니다. 캘린더 내보내기는 수동이며 자동 문자·이메일 발송 기능은 없습니다.


## 묶음 견적·계약 및 외주업체 관리

- 묶음 견적: 하나의 거래처에 여러 상품을 포함하며 수량·단위·판매단가·원가·외주업체·기간을 상품마다 관리합니다. 견적 할인·총액·수금·미수금·예상 매출총이익을 계산합니다.
- 사용 이력: 날짜·수량·메모 기록으로 상품별 잔량 계산. 기록 취소는 원본을 보존합니다.
- 계약 이력: 계약 수정을 저장할 때 이전 상품·가격·원가·기간 정보를 이력에 보존합니다(최근 60회).
- 외주업체: 담당자·연락처·접수방식·접수 URL·은행명·상품별 공급단가를 관리합니다. 보관 처리해도 과거 계약 단가는 유지됩니다.
- JSON 백업에 묶음계약·외주업체 데이터를 포함하며 구형 JSON도 복원합니다.

주의: 고객·계좌 원문은 브라우저 저장 방식에서 안전하지 않습니다. 계좌번호 필드는 비활성화되어 있으며, 실제 고객 정보는 서버 인증·권한·암호화 저장·백업이 마련된 뒤 사용해야 합니다.
