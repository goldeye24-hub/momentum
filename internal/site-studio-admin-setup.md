# 모멘텀마케팅 홈페이지 제작툴 - 관리자 전용 설정

공개 고객 페이지: `/website-samples/`
관리자 로그인: `/admin/` (공개 메뉴에는 노출하지 않음)
기존 `/site-builder/*` 주소는 관리자 로그인으로 이동하며, 템플릿 CSS는 공개 샘플 경로로 복사됩니다.

## 운영 전 필수 설정

Vercel → momentum 프로젝트 → Settings → Environment Variables에서 두 변수 설정:
- `MOMENTUM_ADMIN_PASSWORD`: 16자 이상의 고유한 관리자 비밀번호. 코드나 고객 사이트에 작성하지 마세요.
- `MOMENTUM_SESSION_SECRET`: 추측할 수 없는 무작위 32자 이상의 비밀 문자열. 다른 프로젝트와 재사용하지 마세요.

Production 환경에 설정하고 다시 배포해야 활성화됩니다. 둘 중 하나라도 없으면 로그인 페이지 대신 503으로 차단합니다.
로그인은 6시간 만료되는 HttpOnly·Secure·SameSite=Strict 서명 쿠키를 사용합니다.
운영 전에는 Vercel 보안 기능에서 로그인 시도 속도 제한 및 가능하면 추가 인증을 설정하세요.
정적 샘플과 고객용 갤러리는 공개하고, 관리자 도구 자산은 관리자 인증 후 서버리스 함수가 제공합니다.
주의: 이 공개 GitHub 저장소의 소스 코드를 숨기지는 못합니다. 보호되는 것은 배포된 도구의 관리자 접근입니다.

## 고객 흐름
샘플 선택 → 선택한 디자인 카드 표시 → 해당 디자인 정보가 포함된 제작 상담 폼 → 견적 상담 → 관리자 제작툴에서 편집.
