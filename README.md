# 모멘텀마케팅

## 현재 운영 범위

- **공개 홈페이지**: `/` — 마케팅 서비스 안내, 포트폴리오, 문의 접수
- **보호된 관리자 인증**: `/admin/` — 기존 관리자 세션 인증을 순위 연구실에 제공
- **플레이스 순위 직접 조회**: `/admin/research/` — Chromium 기반 실제 목록 관측. DB 연결이 어려울 때 브라우저 임시기록 지원
- **순위 추적·분석**: `/admin/watches/`, `/admin/keyword-matrix/`, `/admin/place-insights/`, `/admin/competitors/`
- **연결 상태**: `/admin/connection/` — 관리자가 직접 DB 연결을 진단
- **더소통컴퍼니 연결 비공개 조사실**: `/private/kw/:access` — 기존 토큰 인증 유지

## 폐기한 구형 홈페이지 관리자

광고주·외주업체·CRM·재무 장부·디자인 편집·웹사이트 제작 스튜디오의 구형 UI 파일과 URL을 제거했습니다. 공용 인증과 실제 순위관측 엔진은 별도로 보존했습니다.

- 이전 운영 UI의 복구 기준: 커밋 `b6cb4486b43d01491432d21cc9e17f03be23e34c`
- 이전 **브라우저 로컬 저장소는 지우지 않았지만**, 해당 구형 화면을 통해 열람·내보내기는 더 이상 제공되지 않습니다. 필요한 자료가 있다면 위 커밋에서 화면 코드를 복구하여 백업할 수 있습니다.
- 이번 삭제는 공개 홈페이지, 상담 접수 API, 기존 로그인 비밀키, 순위관측 API, 외부 비공개 조사실 코드에는 손대지 않습니다.

## 테스트·운영

GitHub Actions는 `tests/retired-admin-ui.test.cjs`에서 삭제 범위·관리자 세션·순위조회 코드 보존을 검사합니다. Vercel 배포 성공만으로 실제 로그인 및 네이버 관측 성공을 확정하지 않습니다. 실데이터 검사는 로그인된 브라우저에서 별도로 해야 합니다.
