# 모멘텀마케팅 (Momentum Marketing)

> 현재 프로젝트는 **외부 공개 서비스 / 로그인 회원 서비스 / 관리자 운영센터** 3영역으로 운영합니다.
> 기존 홈페이지·도구·저장 데이터를 보존하면서, 기능별 오류와 미구현 항목을 분리해 검증합니다.

| 서비스 영역 | 주소 | 담당 역할 |
| --- | --- | --- |
| **외부 공개 서비스** | `/`, `/lab/` | 브랜드, 온라인 광고 서비스 소개, 무료 진단·순위조회, 문의 |
| **로그인 회원 서비스** | `/platform/` | 내 업체·키워드 등록, 슬롯·측정 이력 |
| **관리자 운영센터** | `/admin/` 또는 `/admin/overview/` | 내부 회원·고객·순위·제작·DB 진단 |
| **기존 제작 스튜디오** | `/admin/studio/` | 기존 관리자의 웹사이트 편집 기능 |

### 서비스 출시의 완료 조건
`코드 작성` → `자동 테스트` → `Vercel Production 배포` → `실제 로그인·DB 동작 검증`.
마지막 단계를 확인하지 못한 기능은 **완료가 아닌 미검증**으로 표시합니다.

- Vercel Production 배포 `READY`는 화면/코드 배포 상태이지 실제 데이터 입력·읽기의 성공을 보증하지 않습니다.
- 서버와 Supabase 직접 조회가 제한되면 **접근 권한/실제 결과 미확인**으로 기록합니다.
- 관리자 CRM·디자인 편집 초안은 로컬 저장 기능을 사용합니다. 서버 동기화 전까지 기존 브라우저 데이터를 초기화하지 마세요.
- 다른 Supabase 프로젝트를 건드리지 않으며 API 키와 비밀번호를 GitHub에 올리지 않습니다.

### QA
`node --test tests/lab.test.cjs`에는 역할 분리·인증·라우팅 회귀 테스트가 포함됩니다.
GitHub Actions는 Chromium 브라우저 테스트 및 공개 Production GET smoke 검사를 별도로 실행합니다.
**프로덕션 회원 가입·관리자 DB 쓰기 검사는 실제 인증/권한 없이 검증 완료로 표시하지 않습니다.**
