# 모멘텀마케팅 — 현재 운영 기준 (2026-11)

## 반드시 유지할 영역
- **공개 모멘텀 홈페이지**: `/` — 서비스 안내, 포트폴리오, 마케팅 자료, 문의 접수
- **현재 관리자**: `/admin/` — 현재 사용 중인 관리자 인증과 각 운영 도구의 공통 진입점
- **관리자 사업 운영**: 광고주·외주업체·거래처/계약(CRM)·매출/손익·디자인·제작 기능의 기존 파일 및 데이터 보존
- **플레이스·키워드 연구**: `/admin/research/`, `/admin/watches/`, `/admin/keyword-matrix/`, `/admin/place-insights/`, `/admin/competitors/`
- **더소통컴퍼니 비공개 조사실**: `/private/kw/:access` — 기존 토큰 및 서버 API 유지
- **콘텐츠·검색 유입**: `/portfolio/`, `/insights/`, 과거 URL의 SEO 리다이렉트
- **문의 접수**: `api/inquiries.js`

## 이번 정리
현재 홈페이지와 관리자 경로에서 사용하지 않는 이전 공개 Lab 진단 API, 구형 루트 스타일·스크립트, 이미 삭제된 `lab/`·`platform/`을 검사하던 테스트, 낡은 관리자/회원 서비스 안내만 제거합니다. 운영 중인 `index.html`, `vercel.json`, `site-builder/**`, `api/admin-site-builder.js`와 순위조회 엔진의 내용은 수정하지 않습니다.

## 유의사항
- CRM·재무 일부 자료는 브라우저 로컬 저장입니다. 해당 브라우저 저장소를 초기화하지 마세요.
- 기존 관리자 화면의 실사용 상태 및 운영 비밀번호는 GitHub 검사만으로 증명되지 않습니다. 변경 후 브라우저 직접 검증이 필요합니다.
- GitHub Actions의 현행 회귀 테스트와 Vercel 운영 배포를 확인합니다.
- 미사용 파일이라도 외부 사용자가 직접 호출한 API는 삭제되면 404가 됩니다. 필요해진 API는 Git 이력에서 복구할 수 있습니다.
