03 / HISTORICAL RANK MATRIX

날짜별 1~100위 순위표

오른쪽으로 스크롤하여 날짜 비교 · 빈칸은 미관측
순위아직 수집된 기록이 없습니다
키워드를 조회하면 저장된 관측 기록이 표시됩니다.

표시된 순위는 모바일 목록에서 관측한 위치입니다. 광고·개인화·지역 설정의 영향을 받으며, 목록에서 읽히지 않은 1~100위는 임의로 채우지 않습니다.

업체별 순위 추이

왼쪽 목록에서 업체를 선택하면 관측된 날짜의 순위를 표시합니다.

연속된 두 날짜에 기록이 없으면 선을 연결하지 않습니다. 이전 데이터가 없는 업체는 신규 진입으로 추정하지 않습니다.

운영 안내

관측 데이터를 만들려면 비공개 Supabase DB와 서버 환경변수를 연결해야 합니다. 네이버 요청 제한(429/403)이 발생하면 재시도를 중단하며, 새로운 값 대신 실제 과거 관측 시각을 표시합니다. 고객용 유료 제공은 데이터 이용 권한과 수용량을 검증한 후 개방합니다.
