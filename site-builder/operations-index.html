01 · 고객 및 회원 운영

거래처·계약·매출 관리 ↗

거래처, 계약 상품, 만료일, 영업 파이프라인. 현재 브라우저 로컬 저장 방식이며 민감한 고객정보 입력은 제한합니다.

서버 저장 미구현 매입·외주비·마진 현황 ↗

계약 판매액·예정원가·실제 외주 지출을 일·월·연 기준으로 집계하며 계산서 수취 여부를 기록합니다.

회원 가입 현황과 무료 파일럿 슬롯 배정을 관리합니다. DB 연결과 회원 실제 업무 흐름 검증이 필요합니다.

운영 통합검증 필요 순위 추적 대상 관리 ↗

업체·검색어 등록, 직접 측정, 관측 결과 조회. 정기 자동 측정은 별도 스케줄 활성화가 필요합니다.

02 · 데이터 및 분석 관리

실제로 저장된 검색 결과를 바탕으로 키워드별 노출 현황을 확인합니다. 관측되지 않은 항목은 빈 결과로 남습니다.

측정 데이터 필요 업체별 키워드 종합분석 ↗

업체 기준 키워드 관측 현황과 이력 분석. 서비스 구축과 실제 데이터 축적을 구분합니다.

측정 데이터 필요 경쟁업체 비교 ↗

동일한 키워드의 경쟁업체 노출 기록 비교. 아직 실사용 검증이 완료되지 않았습니다.
