서버 추적 활성화 조건

DB 테이블은 저장소 db/rank-watch.sql에 준비되어 있습니다. 서버에만 MOMENTUM_RANK_DB_URL, MOMENTUM_RANK_DB_SERVICE_KEY, CRON_SECRET을 연결하고 MOMENTUM_RANK_CRON_ENABLED=true를 설정하면 자동 추적 실행 조건이 준비됩니다. 일정 실행 등록은 실제 연결 확인 후 진행해야 합니다.

파일럿 워커는 호출당 최대 1개 대상을 시도합니다. 모바일 기기 조건으로 측정하며, 페이지 로딩에 실패하면 순위를 만들어 기록하지 않습니다. 운영 화면의 즉시 조회와 일간 서버 추적은 구분합니다.
