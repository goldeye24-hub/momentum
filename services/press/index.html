언론홍보
알려야 할 사실을, 분명하게 전달합니다.

언론홍보는 무조건 기사를 많이 게재하는 것이 아니라 공개할 사실과 의미를 명확하게 정리하는 과정입니다. 발표 내용의 근거와 사용 가능한 자료, 매체별 협의 조건, 광고 여부를 구분합니다.

WHAT WE CAN PLAN

실무에서 확인할 범위

기업·브랜드의 발표할 가치가 있는 소식을 정리하고 보도자료 기획, 사실 검증, 매체 배포 조건과 광고성 기사 표시 기준을 검토합니다.

01 / SCOPE

소재 타당성 검토

신제품·계약·행사·사업 변화 등 보도 가능한 사실 확인

02 / SCOPE

보도자료 원고 기획

회사 정보·발표 내용·근거를 중심으로 전달 문장 정리

03 / SCOPE

매체·배포 조건 확인

매체별 심사와 게재 여부, 광고성 표시 필요성을 구분

04 / SCOPE

이미지·인용 검수

사진 사용권·관계자 인용 동의·사실관계 최종 확인

QUESTIONS & ANSWERS

언론홍보 관련 자주 묻는 질문

보도자료를 보내면 기사 게재가 보장되나요?

아닙니다. 매체의 자체 판단과 심사 기준에 영향을 받으므로, 게재 조건을 확인해야 합니다.

광고성 기사라면 광고라고 표기해야 하나요?

내용과 거래 구조에 따라 관련 표시 규정을 검토해야 합니다. 유료홍보를 독립적인 취재 기사로 가장해서는 안 됩니다.

자료에 고객사 이름이나 사진을 넣어도 되나요?

공개 권한과 당사자·저작권자의 동의를 우선 확인해야 합니다.

어떤 업무부터 필요한지 상담해 보세요.

지역·업종·예산과 현재 운영 상황을 알려주시면 범위를 구분해 검토합니다.
