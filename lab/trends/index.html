03 / USE WITHOUT API ACCESS

네이버 API가 연결되지 않았나요?

네이버 데이터랩의 공식 화면에서 확인한 결과를 **직접 CSV로 정리해 가져오면** 이 페이지에서 검색어 간 흐름을 비교할 수 있습니다. 이 데이터는 서버로 업로드되지 않으며 브라우저에서 처리됩니다.

표준 CSV/TSV 첫 줄: 날짜,부산맛집,부산횟집 · 다음 줄부터 2026-08-01,34.2,62.1처럼 같은 기간의 상대 지수(0~100)를 입력합니다. 예시는 파일 형식 안내일 뿐, 실제 측정 데이터가 아닙니다.

최대 200KB · 기간 열 + 검색어 열 1~5개 · 같은 기간·조건으로 수집한 데이터만 비교하세요.

상대 지수(0~100)

선택한 검색어와 기간 안에서 가장 높은 수준을 100으로 환산한 지수입니다. 실제 월 검색량이나 매출량을 뜻하지 않습니다.

비교 조건 통일

서로 다른 기간·기기·출처에서 가져온 상대 지수는 직접적인 크기 비교가 어렵습니다. 동기간·동조건을 유지하세요.
