01 / 측정 대상

키워드별 순위 확인

무료 베타
순위 측정 방식
네이버 실제 검색 화면 자동 확인

키워드와 플레이스 URL 또는 숫자 ID를 입력하면 브라우저가 검색 결과를 확인합니다. 지도 검색은 현재 화면에서 확인되는 업체만 측정합니다. 화면 미로딩·차단·하위 순위는 임의로 계산하지 않습니다.

조회 제한: 10분당 3회 · 예시 주소: https://map.naver.com/p/entry/place/1234567890

실제 네이버 화면에서 확인한 값만 입력하세요. 못 찾았다면 순위는 미확인으로 기록합니다.

직접 확인한 검색 결과의 이름 목록만 사용합니다. 동일한 상호가 여러 번 나오면 자동 확정하지 않습니다.

블로그 전용 공식 검색 API 조회 — 인증과 표시 권한이 연결되면 상위 100건에서 글 또는 블로그를 찾습니다. 이 결과 위치는 네이버앱 통합검색 화면 순위와 다를 수 있습니다.

이용 시 유의

플레이스 순위는 사용자 위치·검색 조건·기기·개인화에 따라 달라질 수 있습니다. 직접 입력한 값은 사용자 관측 기록이며 자동 검증값이 아닙니다. 자동 플레이스 측정은 네이버 PC 통합검색의 한정된 플레이스 블록 표시 위치입니다. 전체 지도 검색순위와 동일하지 않습니다. API 블로그 결과 역시 실제 통합검색 순위와 같지 않을 수 있습니다. 자동 일간 추적·알림은 아직 연결되지 않았습니다.
