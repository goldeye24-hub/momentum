01 / 측정 대상

키워드별 순위 확인

무료 베타
순위 측정 방식
네이버 실제 검색 화면 자동 확인

검색어와 업체명 또는 네이버 플레이스 숫자 ID/주소를 입력하세요. 모바일 목록은 모바일 화면으로 별도 조회합니다. 동일 상호 중복 가능성이 있으므로 ID 입력이 가장 정확합니다. 목록의 일부만 불러온 경우 순위는 추정으로 표시하며, 찾지 못한 순위는 만들어내지 않습니다.

신규 측정: 10분당 3회 · 동일 조건 30분 이내 재조회는 저장된 값을 재사용 · 네이버 제한(429/403) 시 새 요청 중단 · 예: 퐝물회 또는 2085358113

실제 네이버 화면에서 확인한 값만 입력하세요. 못 찾았다면 순위는 미확인으로 기록합니다.

직접 확인한 검색 결과의 이름 목록만 사용합니다. 동일한 상호가 여러 번 나오면 자동 확정하지 않습니다.

블로그 전용 공식 검색 API 조회 — 인증과 표시 권한이 연결되면 상위 100건에서 글 또는 블로그를 찾습니다. 이 결과 위치는 네이버앱 통합검색 화면 순위와 다를 수 있습니다.

이용 시 유의

플레이스 순위는 사용자 위치·검색 조건·기기·개인화에 따라 달라질 수 있습니다. 직접 입력한 값은 사용자 관측 기록이며 자동 검증값이 아닙니다. 자동 측정은 모바일 플레이스 목록·PC 지도·PC 통합검색으로 측정 범위가 구분됩니다. 모바일 목록을 일부만 불러왔을 경우 전체 검색 순위로 확정하지 않습니다. API 블로그 결과 역시 실제 통합검색 순위와 같지 않을 수 있습니다. 자동 일간 추적·알림은 아직 연결되지 않았습니다.
