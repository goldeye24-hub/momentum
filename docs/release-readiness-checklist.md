# 모멘텀 홈페이지 배포 준비 체크리스트

대상 브랜치: `work/service-structure-v2`  
대상 PR: #1

## 현재 반영된 핵심 범위

- 지식인·상위노출 관련 문구 제거
- 홈페이지·상세페이지 제작 판매 페이지와 상담 연결
- 소상공인 성장진단, 월별 성과 기록, 예산 배분 및 백업
- 개인정보 동의, 연락처 검증, 안전한 오류 안내
- UTM·유입 페이지·이전 방문처 기록
- 구매의도형 가이드와 전용 404 페이지
- 확인된 사업체 정보와 제작 서비스 FAQ 구조화 데이터

## 병합 전 필수 검수

- [ ] 메인·제작서비스·성장진단·가이드·404 페이지를 모바일과 데스크톱에서 확인
- [ ] 내부 링크와 하위 경로의 절대경로 이동을 확인
- [ ] 상담폼 2곳에서 테스트 문의를 각각 1건 발송하고 실제 수신함 도착을 확인
- [ ] 성공·실패·네트워크 오류 때 버튼 상태와 방문자 안내 문구를 확인
- [ ] 전화 링크가 모바일에서 고객센터 번호로 연결되는지 확인
- [ ] 제작범위 진단 결과가 상담서에 자동 입력되는지 확인
- [ ] 성장진단 JSON 백업·복원과 잘못된 파일 차단을 확인
- [ ] 구조화 데이터의 사업체·FAQ 내용이 화면의 실제 정보와 일치하는지 확인
- [ ] 미확인 실적·가격·과장표현·금지 문구가 없는지 최종 검색

## 운영 도메인 확정 후

- [ ] canonical·Open Graph URL을 실제 운영 도메인으로 지정
- [ ] sitemap.xml과 robots.txt를 운영 주소 기준으로 생성
- [ ] 네이버 서치어드바이저와 Google Search Console 소유권·색인 상태 확인
- [ ] 문의 접수 개인정보 파기 담당자와 3개월 이내 처리 절차 확정

## 승인 게이트

다음은 사용자 승인 전 실행하지 않는다.

- PR 병합
- Vercel 운영 배포 또는 기존 운영 배포 승격
- 실제 상담폼 테스트 발송
- 검색엔진 색인 요청
- 광고 집행

## 배포 순서와 중단 기준

1. Preview에서 전 페이지와 진단 흐름을 검수한다.
2. 승인 후 PR을 병합한다.
3. 운영 배포 직후 핵심 페이지와 상담 진입을 다시 확인한다.
4. 승인된 테스트 문의 1건으로 수신을 확인한다.
5. 오류·링크 단절·문의 미수신이 하나라도 있으면 공개 확장을 멈추고 직전 정상 배포로 되돌린다.
6. 안정 확인 후에만 색인과 광고 준비로 이동한다.
