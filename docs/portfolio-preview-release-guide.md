# 모멘텀마케팅 포트폴리오: 디자인 원본 / Preview / Production 운영 규칙

작성 기준: 2026-10-21 / 작업 브랜치 `preview/portfolio-qa-isolation-20261021`

## 1. 단일 원본과 변경 제한
- **운영 코드:** `main` = 실제 고객 사이트. **사용자 승인 없이 직접 수정·병합 금지**.
- **시안 개발:** `preview/portfolio-qa-isolation-20261021` = Vercel Preview 대상. `main`과 별개의 브랜치이지만 같은 저장소이므로 배포 대상(target)이 Preview인지 매번 확인한다.
- **기준 디자인:** 사용자가 이미 첨부한 `법률과_의료를_담은_포트폴리오_end.png` 등 업종별 시안. 승인된 이미지 자체는 현재 Git 저장소에 포함되어 있지 않다. 파일을 확보·버전 고정하기 전에는 자동 픽셀 매칭을 통과했다고 말하지 않는다.
- **신규 디자인 버전:** 승인 시안 → 디자인별 고유 이미지 원본 → HTML/CSS → 실제 렌더링 캡처 → 승인된 갤러리 미리보기 → 운영 배포. 원본 시안 이미지를 잘라 본문 사진으로 재활용하지 않는다.

## 2. 무엇을 '완료'라고 말할 수 있나
| 상태 | 증거 | 가능 표현 |
| --- | --- | --- |
| 코드 작성 | GitHub Preview 브랜치 커밋 | 1차 구현 |
| 경로/정적 검사 | 최신 `node --test` 통과 | 정적 검사 통과 |
| 실제 동작 검사 | Chromium 데스크톱 1440px / 모바일 390px, 버튼·슬라이드·오류·오버플로 검증 | 브라우저 동작 검증 |
| 디자인 검수 | **승인 시안 vs 웹페이지의 실제 PNG 캡처** 직접 비교 후 가독성·폰트·이미지·섹션 확인 | 시각 검수 통과 |
| 최종 승인 | 사용자가 특정 Preview URL/커밋을 승인 | 운영 병합 가능 |
| 운영 반영 | GitHub main SHA = Vercel Production SHA + 실제 URL 재검증 | 운영 적용 확인 |

Vercel `READY`만으로 UI 또는 실제 사용자 동작이 정상이라고 말하지 않는다.

## 3. 현재 소스의 알려진 갭
- `/portfolio/`은 `portfolio/portfolio-home.js`로 `iframe` 미리보기를 생성한다.
- `/portfolio/conversion/`은 실제 스크린샷이 아닌 `gallery-2026.css`의 별도 HTML 카드이다.
- 19개 중 14개는 `reference-collection.css` 공용 레이아웃 의존. 품질 기준을 충족한 업종만 개별 재작성한다.
- 외부 Unsplash 참조 이미지는 원본 시안 이미지가 아니므로 디자인과 동일하지 않다.
- `tests/portfolio.browser.cjs`와 `tests/studio.browser.cjs`는 최신 19종 경로·동작 확인 용도로 업데이트했다. 기존 `18 DIFFERENT` 테스트 문구는 사용하지 않는다.
- **법률사무소:** 독립 구조로 1차 재구현. 승인된 인물 사진 원본이 없어 스톡 이미지가 임시로 사용됨. 시각적 최종 승인 전이다.
- 나머지 업종은 미완료이며, 테스트 통과만으로 '시안과 동일'이라고 표시하지 않는다.

## 4. 승인 절차
1. `preview/` 브랜치에만 수정한다. 반드시 운영 `main`이 변하지 않았는지 확인한다.
2. 자동 검사의 실패 로그를 그대로 보고하고 막힌 원인을 수정한다.
3. GitHub Actions에서 `portfolio-catalog-1440.png`, `legal-reference-implementation-1440.png`, 모바일 390px PNG를 추출한다.
4. 이미지에 포함된 기존 시안 텍스트·버튼을 또 이미지로 넣었는지 검사한다.
5. 업종별 시안과 실제 화면을 대조하며, 사용자 승인을 받는다.
6. *승인 이후에만* PR/병합·Production 배포를 진행한다.

## 5. 인증·고객자료 보호
- Preview에서 관리자·회원 실제 계정으로 테스트하지 않는다.
- 가상 법률사무소 및 의료기관 사이트의 상담/진료 폼은 실제 개인정보를 접수하지 않는다.
- 내부 DB, Supabase 환경변수, CRM 저장 기록을 포트폴리오 재개발을 이유로 변경하지 않는다.
- `main`은 현재 보호된 브랜치가 아니다. 강제 필수 리뷰/검사 규칙은 GitHub 저장소 Settings에서 별도로 설정해야 하며 이 브랜치 생성만으로 자동 강제되지 않는다.
