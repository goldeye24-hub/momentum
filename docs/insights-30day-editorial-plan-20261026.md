## 운영 기준
- 매일 초안 1편. **공개 게시 전 사용자 최종 승인**. 작업용 초안은 /insights/에 공개하지 않는다.
- 타깃: 부산 주요 상권·동 단위 → 양산·김해·울산·밀양·청도·마산·창원 → 전국 홈페이지 제작.
- 우선 키워드는 실제 검색 여부와 네이버 검색광고의 월간 PC·모바일 검색수 및 연관 키워드로 검증한다. **이 표의 키워드는 아직 검증되지 않은 가설**이며 순위/검색량을 보장하지 않는다.
- 지역명만 치환하거나 의미가 같은 콘텐츠를 분리 발행하지 않는다. 예: '서면 미용실 마케팅'과 '부전동 미용실 마케팅'은 검색 의도가 같으면 하나로 묶는다.
- 제목 고유화, 지역별 실제 상황·업종 특성·독창적 체크리스트, 3~5개 FAQ, 모멘텀 11개 서비스와 실제 문의폼 연결.
- 기 게시된 `/guides/homepage-cost.html`, `/guides/place-vs-homepage.html`, `/guides/industry-homepage-features.html`과 내용 중복 회피.
- 기사/정책은 공식 출처 확인·날짜 기록; 허위 사례·가짜 후기·가짜 검색량 사용 금지.
- 매월 말 30개 키워드의 검색 노출·클릭·상담 전환 확인 후 다음 달 편집 일정 갱신.

## 사전 검증
1. 네이버 광고주센터 → 검색광고 → 도구 → 키워드 도구의 검색량/연관어 확인.
2. 검색 결과 상위 페이지의 질문 유형과 겹침 확인, 동일 의도면 문서 통합.
3. 로컬 글은 지역 고유 정보가 있을 때만 해당 동네를 제목에 넣음.
4. 발행 전 공식/1차 출처, 마케팅 규정, 원고 실증 근거 점검.
5. 공개 후 색인 여부 및 유입 키워드를 Search Console/네이버 서치어드바이저로 확인.
