# 모멘텀마케팅 업종별 검색 콘텐츠 30일 편집 캘린더 (개정)
기준: 2026-10-26 · 상태: **키워드 검색량 미실측/승인 대기** · 운영 홈페이지 **미게시**

## 전략
- 매일 새 게시물 **초안 1편**이 목표. 발행은 사람이 실제 효용·중복·사실·검색 의도를 검증한 뒤 승인한다. 양질의 새 글이 부족하면 기존 글 보완으로 대체한다.
- 업종별 30일 배분: 맛집·고깃집·횟집 **8**, 피부관리·에스테틱 **5**, 가발 **4**, 네일샵 **4**, 청소 **5**, 기타(홈페이지 제작 3 + 바이럴 실무 1) **4**.
- 권역: 부산 주요 상권과 동 단위, 양산·김해·울산·밀양·청도·마산·창원, 전국 홈페이지 제작 키워드. 미용실·왁싱·속눈썹·병원·사다리차는 다음 발행 주기 후보로 보관한다.
- 콘텐츠의 독자는 마케팅 서비스를 찾는 **사업주**다. '부산 맛집'처럼 소비자에게 음식점을 추천하는 검색 의도가 아닌, '부산 음식점 광고/홍보/마케팅' 등 업체 운영·광고 문의 목적을 선택한다.
- 모든 키워드는 검색량 확인 **전의 가설**이다. 네이버 광고 키워드 도구로 PC·모바일 검색량/연관 검색어를 확인하거나 검색 결과의 실제 의도를 수동 확인한 뒤 제목을 수정한다. 검색량 없는 숫자를 만들지 않는다.
- 이미 작성된 `docs/insights-drafts/20261026-busan-viral-agency.md`는 기존 초안으로 보존. 이후 날짜는 업종 우선순위에 맞게 재편했다.

## 검색 품질·스팸 방지 게이트 (미달 시 새 글 발행 금지)
1. 같은 의미의 검색어/지역명은 **한 개 문서**로 합친다. 지역명만 바꾼 유사 페이지, 같은 CTA로만 연결되는 도어웨이 페이지를 만들지 않는다.
2. 지역을 제목에 쓰려면 그 지역 독자에게 실질적으로 다른 체크리스트, 확인된 상권·생활권 맥락 또는 서비스 선택 조건이 있어야 한다. 근거가 없으면 부산/경남 같은 포괄 문서에 통합한다. '지역명만 붙인 글'은 게시 금지.
3. 업종 특유의 정보를 제공한다. 맛집은 메뉴·좌석·예약·사진·동선, 피부관리·네일은 시술메뉴/가격/예약설명, 가발은 상담 프라이버시/서비스 범위, 청소는 작업 범위·견적·계약 조건 등.
4. 서론/소제목/FAQ를 기계적으로 반복하지 않는다. 실제 사용자 질문이 없다면 '가상의 사용자 질문'이 아니라 '편집부가 정리한 자주 묻는 질문'이라고 밝힌다. 포럼·작성자·고객·후기·실적·사례를 꾸며내지 않는다.
5. 실제 조사·자사 분석·공식 정책·검증 가능한 비교표·업체 운영 데이터 등 **각 글의 고유 정보**를 요구한다. 검증되지 않은 지역/업종 추정치는 명시한다. 다른 기사를 재작성한 것만으로는 게시하지 않는다.
6. 키워드 반복·과도한 유사 앵커·본문의 무관한 도시명 나열·광고성 FAQ 대량 삽입을 하지 않는다. H1·title·메타 설명은 각 글의 사실적 주제를 정확히 표현한다.
7. 사진/이미지/자료는 출처·권한 확인. 피부관리·가발 관련 글의 의료 효능·시술 안전 주장은 검증 없이 쓰지 않는다. 현장 경험이 없는데 방문하거나 직접 조사했다고 주장하지 않는다.
8. 매 글은 11개 서비스 중 관련 서비스 1~2개와 **실존하는 URL**만 연결한다. 실제 상담은 기존 문의폼 이용. 검색 순위/상위노출/매출 보장 금지.
9. 공개 전 중복 검색의도, 사실확인, 변경 가능한 플랫폼 정책, 검색로봇 접근, 색인, canonical, 내부링크를 점검. 공개 후에는 유입과 실제 문의를 모니터링한다.
10. 월간 30개 초안 생성과 30개 게시를 동일시하지 않는다. 30일 내 모두 발행할 품질이 되지 않으면 보류한다.

## 발행 전 검증·추적
- 동일 검색 의도 판별: 네이버·Google 상위 결과의 검색 목적, 모멘텀 기존 `/insights/` 및 `/guides/` 게시글과 유사성 점검.
- 검색량: 네이버 광고 키워드 도구에서 월간 PC/모바일 데이터가 접근 가능한 경우 확인. 미조회는 명시하고 숫자는 공란.
- 지역 정보: 확인된 사실만 사용, 여러 지역에 적용 가능한 팁은 범지역 가이드로 통합.
- 1차 기준: 유용성·신뢰성·원본성·검색 의도·지역 근거·중복·내부링크 실존 여부.
- 월별 KPI: 색인율, 검색 노출·클릭, 실제 문의 유입, 글별 서비스 연결 클릭.
