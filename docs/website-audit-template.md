## 3. 제안서 한 장 구조

1. 현재 고객이 놓칠 가능성이 큰 지점 1개
2. 공개 화면에서 확인한 근거 2개
3. 우선 수정안 1개
4. 제작 범위: 단일 전환형 / 다페이지 홈페이지 / 구매전환 상세페이지
5. 필요한 고객 자료

## 4. 업종별 접근 초안

### B2B 제조

현재 페이지에서 기술·납품 역량은 보이지만 구매담당자가 문의 전에 확인하는 적용 분야, 품질 근거, 납품 과정이 흩어져 있다면 이 세 항목을 한 흐름으로 재구성한다. 첫 제안은 ‘회사 소개 개편’보다 ‘문의 전 검토자료 정리’에 둔다.

확인 질문: 주력 제품, 주요 적용 업종, 제공 가능한 인증·시험·납품 근거, 문의 이후 견적 절차.

### 포트폴리오형 전문서비스

사례가 많아도 고객 문제·진행 과정·결과가 분리되지 않으면 선택 근거가 약해진다. 대표 사례 3건을 같은 형식으로 정리하고 서비스별 상담 질문을 연결한다.

확인 질문: 수익성이 높은 서비스, 공개 가능한 사례, 고객이 반복해서 묻는 질문, 상담 전 반드시 알아야 할 조건.

### 교육기관·강사

강의 주제 나열 대신 구매자 문제, 대상, 시간, 참여 방식, 결과물, 실제 출강 근거를 한 화면에 연결한다. 문의 폼에는 기관 유형·대상·인원·희망 시기·해결하려는 조직문제를 받는다.

확인 질문: 우선 판매 과정, 공개 가능한 기관 실적, 표준 시간, 운영 지역, 결과보고 제공 여부.

### 병·의원 — 규제검수 전제 TEST

진료과목·접근성·예약 동선 같은 사실 정보부터 개선한다. 치료효과, 우월성, 후기 활용은 관련 법규와 심의 기준을 확인하기 전 제안문에 넣지 않는다.

## 5. 발송 전 게이트

- 공개 화면에서 직접 확인한 내용과 추정을 분리했는가
- 상대 업체의 상호·서비스·URL이 정확한가
- 과장된 문제 지적이나 보장 표현이 없는가
- 무료 시안·과도한 무상 범위를 약속하지 않았는가
- 가격·일정·성과를 임의 확정하지 않았는가
- 외부 발송 승인을 받았는가
