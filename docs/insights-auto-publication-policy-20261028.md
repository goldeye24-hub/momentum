# 모멘텀마케팅 마케팅자료실 자동게시 정책
최종 변경: 2026-10-28 · 운영 범위: 신규 지역형 실무 가이드 · 기존 콘텐츠 삭제 없음

## 발행 권한 및 시스템
사용자 승인으로 검수 통과한 신규 원고는 **별도 매번 승인 없이 자동 공개**한다. 하루(Asia/Seoul 기준) 최대 3편, 0편도 정상이다. 원고 수량보다 정확성, 실용성, 고유성, 구매 의도를 우선한다.
자동 제작 담당은 기존 ChatGPT 일일 자동화 **모멘텀 부산·양산·김해 콘텐츠 자동게시**이다. 각 회차에서 실시간 자료 조사·원고 작성·검증을 수행한 후 GitHub 저장소 `goldeye24-hub/momentum`의 운영 브랜치 `main`을 통해 게시한다. 기존 GitHub Actions `marketing-insights-daily.yml`의 후보 조사와 공식 뉴스 갱신은 별개이며, **후보 생성만으로 게시가 완료된 것이 아니다**.
- 새 글: `insights/guides/<고유-slug>/index.html`에 독립 HTML을 저장하고 `insights/index.html` 안내 카드·`sitemap.xml`을 동시에 업데이트한다.
- 기존 글 중복: 새 경로를 만들지 않고 해당 기존 글을 실질적으로 개정한다. 의미 없는 문장 추가나 날짜만 변경 금지.
- 성공 기준: 내용·링크·정책 검수, GitHub main 커밋, Vercel 프로덕션 READY, 게시 URL 공개 HTTP 200 및 title/H1/canonical/내부링크 확인. 하나라도 미달이면 완료라 표현하지 않는다.
- 확실하지 않은 정보, 확인되지 않은 가격·정책·수치·업체 성과, 라이선스 없는 이미지, 부적절한 비교광고, 규제 업종의 위험한 표현, AI가 만들어 낸 체험·후기는 자동 발행 금지.
- 이미지는 권리가 증명된 자산만. 준비되지 않았다면 가짜 이미지 대신 의미 있는 HTML 체크리스트·비교표 등으로 대체한다. 없는 이미지를 있다고 적지 않는다.
- 게시글에는 출처·검증 날짜, 작성 주체, 실무 적용 제한, 적합한 모멘텀 서비스 링크와 상담 동선을 제공한다.

## 지역 우선순위: 큰 지역 → 작은 지역
신규 지역형 SEO·GEO 콘텐츠 대상은 **부산광역시, 경상남도 양산시, 경상남도 김해시** 세 도시로만 제한한다. **사용자 승인 전 지역 확대 금지**. 기존 다른 지역 글은 그대로 유지하되 신규 지역형 발행 대상으로 삼지 않는다.
1. **1차(도시+세부업종)**: `부산 입주청소 광고`, `양산 네일샵 마케팅`, `김해 사다리차 광고`처럼 부산·양산·김해와 실제 업종별 구매 질문을 조합. 단, 예시는 검증된 검색량·수요를 의미하지 않는다.
2. **2차(구·생활권+세부업종)**: 부산 해운대구·사상구·부산진구 등 구 단위, 양산 물금·덕계·사송 생활권, 김해 장유·율하·삼계 등 실제 구분되는 생활권. 도시 단위 콘텐츠를 어느 정도 축적하고 독립된 검색 의도가 확인된 후에만 확장.
3. **3차(동·상권+세부업종)**: 전포동, 서면, 광안리, 센텀시티 등 동·주요 상권 및 양산·김해 세부 생활권. 상권 특성, 이용 고객, 문의·예약 맥락이 실증되어 **도시 상위 글에서 답변하지 못하는 고유한 문제**가 있을 때만 개별 발행.
- 각 계층에서 동일 업종은 비교 정보·고객 고민·행동 동선이 달라야 함. 지역명만 치환하거나 전국 지역 목록에 대응해 페이지 자동 생성 금지.
- 기본 순서는 상위 도시 콘텐츠 축적 → 충분한 고유 문제 확보 시 구·생활권 → 동·상권. 검색량 또는 실제 고객 수요에 따라 특정 작은 지역 주제를 먼저 선정할 수 있으나 예외 이유를 보고해야 한다.
- **키워드 소진 신호**: 14일간 독립적으로 검증되는 상위 지역 키워드 부족, 중복 주제 반복, 신규 후보 검수 탈락 증가, 기존 글 내에서 이미 질문이 충족되는 상황. 소진 징후가 보이면 구·동 단계 확대 가능성부터 검토하고, 세 도시에서도 더 이상 독립적인 검색 기회가 없으면 사용자에게 확대 지역과 근거를 **먼저 보고**한다. 승인이 없으면 외부 지역 신규 글은 게시하지 않는다.

## 신규 발행 업종 허용 목록 — 사용자 확정 105개 / 11개 분류
2026-10-28 기준 **단일 기준 파일** `docs/insights-approved-industries-20261028.json`의 `industryCount: 105`, `exclusive: true`, `groups`를 매회 먼저 읽고, 등록된 105개 업종 중에서만 신규 지역·업종 콘텐츠를 선택한다. 이전 79개 업종, 무제한 후보 확장, 이 문서의 과거 예시, 30일 옛 편집표는 신규 업종 추가 권한이 아니다. 승인되지 않은 치과·피부과·건강검진센터·차량광택 등도 별도 승인 전 새 글 주제로 사용 금지. 사용자 확인 전 다른 업종 자동 확장 금지. 다만 기존 게시물의 기록은 보존하고, 필요할 때 사실 오류를 정정할 수 있다.

11개 분류: 음식점·외식·식품 12 / 뷰티·미용·헤어 11 / 웨딩·한복·행사 9 / 청소·이사·생활서비스 18 / 의료·건강 2 / 교육·여가·숙박 14 / 자동차·반려동물 5 / 인테리어·주거·시공 7 / 전문서비스·B2B 8 / 마케팅·광고·제작업 13 / 소매·온라인·기타 6. **세부 업종명은 JSON 원본만 정본**으로 적용. 날마다 최대 3개는 가능하면 검색 목적과 업종을 다르게 구성하며, 이름만 바꿔 똑같은 해결법을 재출판하지 않는다.

## 업종별 마케팅과 홈페이지 제작 의도 병행 심사
사용자가 허용한 **105개 업종 안에서만** 마케팅 실행 가이드뿐 아니라 "홈페이지 제작·비용·필수 기능·제작 vs 플레이스/SNS 비교"처럼 웹사이트 구매 의도가 있는 콘텐츠도 선정할 수 있다. **홈페이지가 필히 필요하다고 단정하지 않는다.** 고객 의도·예산·예약/견적·자료 전달·문의 추적·온라인 판매·브랜드 신뢰·지점 안내·구조화된 정보·소유 매체 필요성을 판단해 다음 세 등급으로 근거를 설명한다.
- **홈페이지 우선 검토**: 여러 서비스의 견적 항목·시공 사례·프로젝트 요청서가 필요한 입주청소/인테리어/시공·기업교육, 상품·규격 비교가 필요한 가구·침구/렌탈, 시설·행사·패키지·예약 상세가 중요한 웨딩홀/펜션·풀빌라 등. 이는 *사전 가설*이며 실제 업종·키워드의 검색 의도를 확인한 뒤 글의 핵심 주제로 결정한다.
- **조건부 제작**: 식당/카페/네일샵/속눈썹/미용실/사진관 등은 플레이스·예약·SNS만으로 목적을 달성할 수 있는지 우선 확인하고, 온라인 예약·다점포·브랜드 정보·다국어·다양한 메뉴/서비스 등의 복잡성이 있다면 사이트를 제안한다.
- **제작보다 운영 도구 우선**: 단일 시술/서비스·소규모 생활 밀착·간단 전화 상담 중심 업종은 플레이스·지도·검색광고·전화/메시지 동선 최적화가 먼저일 수 있다.
- 규제 업종은 광고·표시·운영·개인정보와 관련된 공식 규정을 확인하고 "웹사이트 제작만으로 합법/신뢰 확보"와 같은 단정 금지.

홈페이지 제작 키워드가 검증될 때는 **도시 + 업종 + 홈페이지 제작**(예: 부산 웨딩홀 홈페이지 제작, 양산 입주청소 홈페이지 제작, 김해 기업교육 홈페이지 제작)을 먼저 검토하고, 상위 단계의 독립적 콘텐츠가 확보된 후 구·생활권 → 동·상권으로 확장한다. 키워드 예시가 실제 검색량을 뜻하는 것은 아니다. 한 업종의 일반 마케팅 글과 홈페이지 제작 글을 분리하려면 대상 문제·검색 의도·독자 가치·본문 내용이 실질적으로 달라야 하며, 그렇지 않으면 기존 마케팅 글의 "홈페이지가 필요한 조건" 절로 통합한다.

홈페이지 제작형 글에는 업종별 필요한/불필요한 기능, 제작/유지 비용 결정 요소(근거 없는 가격 수치 배제), 제작 일정과 자료 준비, 모바일/SEO·GEO/문의·예약, 유지보수·소유권·계약 확인사항, 플레이스/SNS와 비교, 실제 제작 가능 범위 및 `/services/websites/` 내부 링크를 기본적으로 검토한다. 프랜차이즈에 적합한 실무 주제만 `/services/websites/franchise/` 링크를 사용한다. 단순히 모든 업종에 "홈페이지 필수" 또는 "홈페이지 제작 업체" 문구를 반복 삽입하지 않는다.

## 검수/보고
각 게시 원고: 유일한 title/H1/meta description/canonical, 실제 확인한 1차 공식 근거 또는 출처, 검색 질문 직접 답변, 업종별 구체적 체크리스트·비교표·상담 의사결정, 중복 검사, 내부링크, 모바일 읽기, 실재하는 CTA, 이미지 사용권 확인. 심각한 불확실성·의미 없는 반복·근거 없는 지역 추정이면 발행 보류.
게시 일보: 검증된 주제 후보 수, 실제 게시 수와 URL/상태, 보류와 이유, 지역 계층(도시/생활권/동·상권), 다음 확장 단계 판단, 월간 색인·클릭·문의 변화. Vercel 또는 GitHub 문제가 있으면 실패로 보고하고 발행 완료를 주장하지 않는다.
