## A. 공개 홈페이지 — 신규 고객 유치
- 소개·설득: 모멘텀의 접근법, 문제 해결 방식, 서비스 차별화, 과정, 성과 증빙.
- 마케팅 상품: 플레이스·로컬 SEO/검색광고, 블로그·바이럴, SNS, 홈페이지, 상세페이지, 통합 광고대행. 마케팅 가격·혜택 과장 금지.
- **마케팅 최신 트렌드 및 정보**: 플랫폼 변경·현장 전략·업종별 사례. 날짜·출처·업데이트 시각 표기. 관리자에서 글 검수·발행.
- **포트폴리오 독립 3분류**: 홈페이지, 상세페이지, 브랜드블로그(홈 디자인/브랜딩/운영). 실제 납품 vs 데모 구분; 고객 허락과 저작권 준수.
- 광고 문의: 업종·상호·연락처·기대목표·선택 상품; 상담/견적 CRM으로 연결.
- 무료서비스 독립 4개:
  1. 키워드 검색량 조회(측정치 및 출처/측정일 표시)
  2. 플레이스 순위 확인 **비회원 하루 2회**(실측 성공만 순위로 표시; 기준 위치·기기·키워드·관측시각·범위를 명시; 오남용·봇 차단 및 분산 쿼터 설계)
  3. 상권정보(공식/공공 데이터 기반 점포·업종·변화, 유동인구·매출·실시간 현황은 확보 전 미제공)
  4. 시즌별 검색어 추이(상대지수와 실제 검색량 구분)
- 홈페이지 메인: 전문 광고대행사 브랜드 중심; 분석도구/회원 영역은 분명한 CTA. 모바일 우선.

## B. 회원 플랫폼 — 핵심 상품
**기본 질문: 내 매장이 어디에서 얼마나 노출되는가? 경쟁업체보다 부족한 점은? 무엇을 수정할까? 수정 후 실제 개선되었나?**

### 필수 입력 및 근거
- 상호, 업종, 지점, 지역/상권, 네이버 플레이스 숫자 ID 또는 URL; 선택: 홈페이지, 블로그, SNS, 대표 키워드, 문의/예약 목표.
- 선택적 연결/승인: GA4, Search Console, 네이버 관련 계정/분석, 광고계정 등. 미연결 데이터는 보유하지 않는다고 정확하게 표시.
- 결과마다 측정 시점, 기기·지역·검색 표면, 측정 방식, 출처, 신뢰도, 측정 실패 상태. **측정하지 않은 순위/조회수/경쟁사 매출을 임의 생성하지 않음**.
- 대상 상권·업종·검색 의도별 비교집단을 구분. 경쟁사 자료는 합법적으로 확보한 공개 데이터·승인 데이터만 사용.

### 대시보드와 진단 엔진
1. **내 매장 종합 성적표:** 포털 플레이스/웹검색 실제 관측 순위, 가용한 검색 노출/클릭/문의 지표, 자사 진단 종합·영역 점수. 공식 알고리즘 점수로 속이지 않음.
2. **SEO 진단:** 사이트 접근/색인, title/description, 지역·메뉴·서비스 정보, 구조화 데이터, 중복 콘텐츠, 모바일/전환 흐름; 가능한 근거별 수정 조치.
3. **GEO 진단:** 생성형 AI 서비스에서의 출처 인용/브랜드 언급 여부와 기본 정보 일관성·명확성·근거 표시 평가. 자체 측정/가설이며 AI 노출 보장·공식 점수 아님.
4. **플레이스 개선:** 업체 정보·분류·영업시간·메뉴/가격·사진·예약/문의 동선·대표 키워드와 검색 의도 정합성·리뷰 응대.
5. **경쟁업체 비교:** 같은 지역/업종/키워드의 실제 관측 순위 및 확인 가능한 정보 완성도, 리뷰 수·속성·콘텐츠, 검색 노출 격차. 순위를 좌우하는 공식 가중치를 안다고 주장하지 않음.
6. **개선처방/실행 체크리스트:** `문제 근거→영향 가능성→추천 변경→실행 방법→난이도·비용·우선순위→완료 여부→재측정` 흐름. 수행 도구/콘텐츠 초안·담당자·상담전환.
   - 블로그: 부족한 검색 의도/정보와 보유 콘텐츠를 비교하여 업데이트/새 콘텐츠 주제와 이유 제안. 단순 업로드 횟수 증가를 기계적으로 처방하지 않음.
   - 영수증/방문자 리뷰: **실제 이용자의 자발적·진정한 경험** 유도와 응대 가이드. 허위·대리 리뷰, 보상 조건을 숨긴 후기, 획일적 키워드 삽입 지시 금지.
   - 트래픽·광고: 측정 가능한 유입/전환/광고 경쟁 상황을 확인했을 때 비용 대비 가능성을 설명하며 예산 제안. 연결되지 않은 통계는 미확인으로 표시.
7. **성과 추적:** 7/30/90일 순위 기록, 작업 전후 비교, 조회/클릭/전화/예약 등 연결 가능한 지표, 리포트와 알림.

### 자체 개발 애드로그형 기능 — 참고기능 전체 관리 원칙
- 핵심: 플레이스 ID/기본정보/히든키워드 후보·순위·변동·리뷰·저장 지표, 1회 조회, 키워드/경쟁사 추세, 블로그 게시물 순위, 통합웹 순위, 인플루언서 순위, 키워드 조합/확장.
- 확장 대상 목록: 펜션 예약 관련 순위, 쇼핑 가격비교, N+ 스토어 관련 순위, 기타 공식 사이트에 명시된 도구. 로컬 사업자 중심 핵심 UX와 분리하고 수요/데이터 권한/개발비 검증 뒤 단계적 공개.
- **지식인 관련 서비스는 종전 제외 지시 보존**. 기능 전체 재현과 충돌할 경우 별도 승인 전까지 공개·판매·우선개발에 포함하지 않음.
- 경쟁 서비스의 내부 소스/상표/비공개 API를 복제한다는 뜻이 아님. 제공 가치와 기능 범위를 자체 구현하되 자료 수집 및 상업 이용권 검증이 필요.
- 회원 소유권 기반 목표/슬롯/기록 분리, 결제·구독·권한, 자동 스케줄, 분산 요청 한도, 실패/429 방어 및 비용 상한 설계.

### 점수와 설명의 신뢰성
- 점수는 **모멘텀 자체 체크리스트/휴리스틱**. 공식 네이버·구글·AI 랭킹 점수와 구분하고 항목별 근거/측정일/산식·범위를 노출.
- 미측정 지표는 null/미확인, 가짜 0점 금지. 경쟁 비교 표본과 기준을 명시.
- 결과는 확률적 가설·개선 후보이지 '이 조치를 하면 N위 상승'을 보장하지 않음.

## C. 관리자 통합 운영센터
- 회원·이용권·결제·영수증/환불·권한/접근 로그 및 회원별 데이터 격리.
- 도구·API 통제: 무료조회 일일 2회(공유 서버/DB 기준), 대상/키워드 슬롯, 자동 수집/정기 작업, 429/403 제한, 실측 실패 큐·수집 비용·오류 로그, 외부 데이터 계약.
- 고객·영업 CRM: 유입 문의→상담→견적→계약→작업→청구→재계약.
- 사이트·광고: 마케팅 상품, 포트폴리오, 트렌드 글, SEO, 배너/팝업/광고영역, 상담 유도 및 광고 소재.
- 통계·오류: 방문→무료 도구 사용→회원가입→유료 전환→상담/계약 퍼널, 가입/활성/이탈, 배포·DB·API 오류, 감사로그. 데이터 자체 미수집일 때 추정 숫자 표시 금지.
- 마케팅 실행/게시/발송/광고비 등 고객 영향을 주는 조치는 관리자 확인 후 수행.
- 기존 `/admin/studio/`의 제작 도구, 로컬 CRM/디자인 백업, Supabase 데이터를 파괴하지 않음.

## 우선순위/완료 정의
- **P0:** 기존 DB/실측/회원 E2E/세션·권한 오류, 운영 배포 일치, 기록 신뢰성.
- **P1:** 공개 메뉴·포트폴리오/무료 4종 안정화(실제 데이터), 회원 진단 엔진 기초 + 비교/실행처방 실증.
- **P2:** 자동 모니터링·알림·구독/결제, 추가 애드로그형 범위, 관리자 CMS/통계 확대.
- 각각 `요구사항→코드→자동테스트→배포→운영에서 실사용 검증` 단계로 기록. 마지막 미확인 시 **완료 아님**.
