## 0. 기획 3줄
- **목적:** 첫 방문자가 '무슨 서비스를 하나'뿐 아니라 '왜 이 업체에 상담해야 하나'를 이해하고 전화·폼·도구 진입으로 이어지게 한다.
- **타깃:** 소상공인/지역 업체 대표와 마케팅 담당자, 복수 점포 운영자, 검색광고/플레이스/체험단/인플루언서 통합 운영이 필요한 사업자.

## 2. 경쟁사에서 배울 내용과 복제하지 않을 내용
- 참고: STEW는 외식업 전문성을 전면에 두고, 마케팅 회사를 믿기 어려운 고객 심리, 직접 점검하는 항목, 실제 플레이스 유입 비교·현장 경험, FAQ, 상담 동선을 잇는다.
- 차별화: 모멘텀은 **종합 온라인 광고대행사**를 유지하므로 외식업만 전면에 두지 않는다. 식당·뷰티·교육·숙박·전문서비스 등 업종별 다른 전환 흐름을 보여준다.
- **복제 금지:** 사이트 이미지·레이아웃 세부·브랜드 표현·고객사 이름/성과·수치/리뷰를 그대로 사용하지 않는다.

## 4. 실제 화면 구성 / 카피 초안
### 01 히어로 (가장 높은 시각적 비중)
- 눈썹 라벨: `MOMENTUM MARKETING · INTEGRATED DIGITAL AGENCY`
- 큰 제목: **"검색에서 끝나는 광고가 아니라, / 선택으로 이어지는 마케팅."**
- 서브: "네이버·구글·카카오 검색광고부터 플레이스·콘텐츠·SNS까지. 업종과 지역, 고객의 검색 의도에 맞춰 필요한 일부터 설계합니다."
- 행동1: **우리 사업 마케팅 상담** → 기존 `#contact`
- 행동2: **무료 마케팅 도구 체험** → 기존 `#free-tools` 또는 `/lab/`
- 신뢰 문구: 10년+ 경력은 사업자/담당자 근거 확인 후 유지. 증빙 전에는 '다양한 업종의 마케팅 운영 경험'처럼 비수치 표현.
- 오른쪽 아트: 지금의 반복 카드/장식적 엔진 대신 **'발견→비교→예약/문의' 3단계 압축 도식과 실제 사용 화면 일부**(자체 화면 또는 권한 있는 디자인 소재). 추상적인 KPI 숫자 사용 금지.
- PC: 카피 55% / 아트 45%. 모바일: 카피→CTA→아트, 핵심 제목을 첫 화면에서 읽을 수 있게.

### 02 고객 불편(신뢰의 시작)
제목: **"광고를 했는데, 왜 문의는 그대로일까요?"**
문제 표현:
- 검색 결과에 보이지만 고객이 매장을 선택할 정보가 부족합니다.
- 광고비는 나가는데 키워드와 문의 경로가 연결되지 않습니다.
- 블로그·SNS·플레이스가 제각각 운영됩니다.
- 무엇부터 고쳐야 하는지 알기 어렵습니다.
결론: "예산을 늘리기 전에 고객이 어디에서 멈추는지 확인합니다."
그래픽: 4개 똑같은 카드 대신 **좌측 큰 문장 + 우측 실제 고객 여정 병목 도표**. 문제 상황 예시임을 표기.

### 03 차별화된 방법론
제목: **"광고 상품을 먼저 권하기보다, 막힌 지점부터 찾습니다."**
`고객 검색 → 클릭 → 정보 비교 → 문의/예약 → 운영 점검`
각 지점에 실제 업무: 키워드·매체 점검/플레이스 정보·사진/콘텐츠·SNS/상담 동선/측정항목.
검증되지 않은 완전 자동 AI 진단이나 실제 컨설팅 방문을 일반 제공 항목으로 단정하지 않는다.

### 04 대표 사례(가장 큰 신뢰 섹션)
카피: **"설명보다, 무엇을 실제로 바꿨는지 보여드립니다."**
- 실제 허가된 케이스 2~3개를 비대칭 에디토리얼 레이아웃으로:
  A (대형) 플레이스: 전/후 사진·정보 구성과 작업 목록.
  B (중형) 검색광고: 키워드/광고구조 개편과 수정 근거.
  C (작형) 블로그·SNS: 콘텐츠 기획/게시 산출물.
- 증거 카드 필수 데이터: **업종/지역·처음 문제·실제 수행·기간·확인 기준·결과(있는 경우)·한계/외부 변수·자료 사용 동의**.
- 숫자는 증빙 가능할 때만 원시 데이터/기간과 함께 표시. 실제 성과 없는 경우 작업물 스크린샷·고객 허가·실제 프로세스로 신뢰를 형성.
- 기존 포항 묵돌이/발몽헤어 사진을 허가 없이 메인에 재사용하지 않음.

### 05 서비스 소개(목록에서 선택지로)
헤드라인: **"상황에 맞게 필요한 서비스를 연결합니다."**
1차 대형 서비스 4분류: 검색광고, 플레이스 SEO·예약 점검, 바이럴/체험단, SNS/인플루언서.
2차 간결 링크: 리뷰관리, 언론홍보, 촬영대행, 광고교육.
- **디자인**은 모멘텀에이전시 `/agency/`로만 연결, 메인의 주력 서비스로 강조하지 않음.
- 가격 정보는 실제 확인된 것만. '효과 보장' 표현 배제.
- 8개 기존 `/services/*` 세부 URL은 유지. CTA의 `?service=...` 상품 자동 선택도 유지.

### 06 업종
공통 문구: **"업종이 다르면 고객의 선택 기준도 다릅니다."**
업종 4개 사례 카드 대형 사진(허가/스톡 명시) + 두세 줄 문제 → 실행 항목 → 상세 링크.
병의원·건강 관련 업종은 광고법·심의 기준과 의료광고 규정 확인 후 별도 문구로 제한.

### 07 교육·도구
- 무료 키워드·순위·기초 점검 도구는 실연동/사용 가능 상태에 맞춰 표기. API 미연결은 실시간/완전자동처럼 과장 금지.
- 광고교육: "3시간 직접 배우는 로컬 광고 운영", 커리큘럼(기초/플레이스 실습/검색광고/바이럴) + **교육 후 60일 카카오톡 지원**. 질문 범위·응답시간·AS 규정을 최종 확인 후 본문/상세/FAQ 동기화.
- 유료 회원서비스는 개발 중 기능을 판매 가능하다고 보이지 않게 '준비 중'으로 처리하고 하단 보조 영역으로 내림.

### 08–10 견적/프로세스/상담
- 오픈패키지 1·2는 한눈에 비교 가능한 요약, 기존 상세한 설명은 별도 페이지/상담.
- 결과물 미리보기: 체크리스트, 광고그룹 구성안, 진행 내역, 촬영 컷 구성처럼 실무자가 무엇을 받는지 설명.
- 상담 폼: 첫 화면에 핵심 4필드(상호·업종, 연락처, 필요 서비스/현재 고민, 동의) 중심; 추가 정보는 선택으로. 실제 개인정보 처리 동의와 스팸방지·기존 Web3Forms 연결 유지.
- 전화 클릭, 상담 버튼, 서비스 상세 이동, 무료 도구 시작, 상담 성공을 GA4 이벤트로 측정. 목표치는 기준 데이터 확인 뒤 설정.
- 비용/계약 주의사항: 광고 매체비와 대행비 구분, 노출·매출·리뷰 삭제 보장 금지.

## 5. 디자인 시스템 (고급 브랜드형 / 카피 중심)
- 디자인 키워드: **Editorial / Evidence / Contrast / Precision**.
- 메인 바탕: 아이보리 화이트 `#F7F9FC`, 본문 잉크 `#10213D`, 짙은 네이비 `#0A1E40`, 브랜드 코발트 `#3167E8`, 보조 하늘 `#B7D9FF`. 강조색은 메인 CTA에만.
- 구성: 섹션별 ① 화이트 타이포, ② 딥네이비 도표, ③ 대형 실제 이미지, ④ 오프화이트 에디토리얼 사례처럼 리듬 변경. **모든 구간 카드 3~4장 반복 금지**.
- 타이포: 첫 화면 H1 PC 66~84px(반응형 clamp), 모바일 38~46px, 짧은 행, 2–3행. 섹션 H2 PC 40~56px, 모바일 29~36px. 수치는 강한 대비와 출처 병기.
