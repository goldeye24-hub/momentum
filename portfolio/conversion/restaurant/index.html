FREQUENT QUESTIONS

방문 전 확인할 내용

실제 메뉴 가격은 어디에 표시되나요?

고객사에서 확인된 메뉴표와 가격을 제공하면 메뉴 섹션에 표시합니다. 이 시안에는 가상의 금액을 넣지 않았습니다.

지금 예약할 수 있나요?

현재는 가상 디자인 시안입니다. 실사이트 제작 시 네이버 예약이나 실제 전화 링크를 연결합니다.

검색 노출이 보장되나요?

페이지 제목, 콘텐츠, 검색엔진 접근성을 최적화하되 검색 순위나 예약 실적을 보장하지 않습니다.
