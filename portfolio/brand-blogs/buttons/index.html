02 / 메뉴 버튼 & 링크

버튼명과 연결할 정확한 URL을 각각 입력하세요. 이미지 버튼은 PNG로 내려받습니다. URL 미입력 시 버튼 클릭은 새 사이트로 연결되지 않습니다.

03 / 네이버 블로그 위젯용 버튼 코드

네이버 계정에서 버튼 PNG를 먼저 업로드하여 얻은 이미지 주소를 입력해야 실제 위젯 코드가 완성됩니다. 링크와 이미지 주소를 모두 입력한 버튼만 코드로 표시됩니다.

PC용 스킨 타이틀

PC 꾸미기 설정의 타이틀·배경에 적용할 자산입니다. 실제 표시 높이와 위치는 스킨에 따라 다릅니다.

모바일 블로그 커버

모바일 블로그 홈은 별도 편집 영역이므로 PC 위젯이 동일하게 표시된다고 가정하면 안 됩니다.

04 / 네이버 블로그 적용 방법

  1. PC·모바일 커버 이미지와 각 메뉴 버튼 PNG를 내려받습니다.
  2. 네이버 블로그 관리 → 꾸미기 설정 → 세부 디자인 설정에서 타이틀·스킨을 조정합니다.
  3. 관리 → 꾸미기 설정 → 레이아웃·위젯 설정에서 위젯 사용·위치를 설정합니다.
  4. 버튼 이미지를 네이버에 올리고 이미지 주소 및 정확한 링크를 넣어 위젯 코드를 완성합니다.
  5. 실제 블로그에서 PC 버튼 연결과 모바일 화면을 각각 테스트합니다. 위젯 HTML 허용 범위나 스킨에 따라 적용을 조정해야 합니다.
