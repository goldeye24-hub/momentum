네이버 키워드 월간 검색량

PC·모바일 월간 검색량은 네이버 검색광고 키워드 도구의 인증된 자료를 사용해야 합니다. 현재 연구 환경에는 검색광고 인증 키가 연결되어 있지 않아 실제 조회 기능을 활성화하지 않았습니다.

연결 대기 · 인증된 검색량을 제공하기 전까지 수치를 생성하지 않습니다.

네이버 데이터랩 · 화면 안에서 보기

네이버 원본 검색어 트렌드 페이지를 아래 프레임에 표시합니다. 네이버가 다른 사이트의 프레임 표시를 차단하는 경우에는 원본 사이트로 이동해야 합니다.

네이버 원본 사이트 열기 ↗

프레임 표시 가능 여부는 아직 확인하지 않았습니다.

화면이 비거나 접속 거부 메시지가 나타나면 네이버의 프레임 표시 제한입니다. 위의 '네이버 원본 사이트 열기'를 이용하세요.

모멘텀 내부 검색어 추이 그래프

공식 네이버 데이터랩 API로 검색 관심도 지수(0~100)를 직접 그래프로 표시합니다. 절대 검색량과 다릅니다.

네이버 공식 API 인증정보가 연결되면 실제 검색 추이를 조회할 수 있습니다.
모멘텀마케팅 내부 연구 프로젝트. 운영 홈페이지 메뉴에는 연결하지 않았으며 공개 지표로 검증되지 않은 결과는 순위 보장 자료로 사용할 수 없습니다.
